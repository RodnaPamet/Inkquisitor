# 2026-11-19 — 0.H Phase 0 hardening

## Design

Phase 0.H verifies the Phase 0 claims by test and closes issues #5 to #11.
Each brief item is held by something that fails when the property breaks,
not by a reading of the code.

```
request ─▶ src/proxy.ts (Next 16 proxy, Node runtime; was src/middleware.ts)
            ├─ nonce = generateNonce(); csp = buildCspHeader(nonce)
            ├─ rate-limit tiers, keyed on clientIpFrom(headers)          (#5)
            │    = X-Forwarded-For entry TRUSTED_PROXY_HOPS from the right
            │    every log line names the request id                     (#7)
            ├─ workspace gate (0.3)
            └─ every response it returns: x-request-id + CSP + SECURITY_HEADERS
                 forwarded request: x-csp-nonce + the CSP (Next stamps its scripts)
        ─▶ root layout: theme script + __webpack_nonce__ bridge carry the nonce
        ─▶ /_next/static, /_next/image: next.config.mjs headers() (STATIC_ASSET_CSP)

sign-in ─▶ authenticateWithPassword ─▶ lockoutFor(policy)                 (#10)
             Upstash (configured) | Redis (production) | memory (dev/test)
             a failing shared store degrades to process memory

membership UPDATE/DELETE ─▶ workspace_membership_last_owner_guard         (#11)
             same advisory key as members.ts, P0001, cascade passes
```

## Decisions

- **The proxy runs on Node, so "the edge bundle" is now the proxy bundle.**
  Next 16's `proxy.ts` takes no `runtime` option and always runs on Node.js;
  there is no edge bundle left for the Upstash warning to come from. The issue's
  intent is kept anyway: the proxy imports `@upstash/redis/cloudflare` (the
  fetch-only entry), and its graph is held free of Node built-ins and Node-only
  packages by a source guard with a closed package list. The built
  `.next/server/middleware.js` necessarily contains Next's own Node adapter
  (http, crypto, zlib), so the build check names forbidden MODULES by a string
  only each contains, not Node built-ins.
- **`build:check` fails on every `⚠` line, not only the two named.** A build
  that prints warnings is one nobody reads. webpack's `<w>` persistent-cache
  notices (next-intl's dynamic `import()` in its extractor, printed only on a
  cold `.next`) are infrastructure logs, not compilation warnings, and are not
  counted; fixing them needs next-intl upstream. `next-auth/react` reads
  `process.env.NEXTAUTH_URL` in its client code by itself; that one name is on
  the check's closed `LIBRARY_CLIENT_READS` list.
- **Client address with `hops = 0` is one shared bucket.** Neither a route
  handler nor the proxy can see the socket address, so trusting no header
  leaves nothing to key on but a constant: the safe failure (one budget for
  everyone) rather than one budget per header value. `X-Real-IP` is no longer
  read: Caddy does not set it and passes a client's own through. A malformed
  trusted entry is the shared bucket too, never the string itself.
- **The lockout store is Upstash, else Redis in production, else memory.**
  Production already requires `REDIS_URL`, so "memory only in development"
  needs no new variable. The Redis client is its own, with bounded commands
  (`commandTimeout` 1.5 s), so a Redis outage costs a sign-in seconds, not the
  request. A failing store DEGRADES to process memory (logged): it neither
  stops sign-in nor switches the lockout off.
- **The ioredis leak was a closed socket waiting to close.** `disconnect()`
  arms a 2-second timer that waits for the socket's `close`; a refused socket
  had already closed. `closeRedisClient` QUITs a ready client, and for any
  other state disconnects and emits `close` on a socket that is already
  destroyed. The Sentry report from `--detectOpenHandles` was an
  `AsyncLocalStorage.snapshot()` the SDK takes at import; it did not hold the
  process, but it is gone with the lazy import.
- **`stripTags` decides on the output.** One input pass; a tag-start character
  arriving after a `<` already in the output turns that `<` into a tag, removed
  up to the next `>` the output receives — what a second strip would remove.
  Every `<` left is followed by a character that cannot start a tag (a fuzz
  case over tag fragments holds that), and 100 KB of crafted nesting takes
  milliseconds.
- **The trigger lets the cascade pass by asking whether the workspace still
  exists.** By the time a cascade deletes the memberships, the workspace row is
  gone in the same transaction. A user deletion is NOT exempt: deleting the last
  OWNER's account fails until the workspace is dealt with. The 0.3 isolation
  test that moved A's only OWNER into B now moves a non-owner (the trigger
  refuses the owner first, so the old case no longer tested the policy) and
  checks the owner row separately.
- **CSP style-src keeps `'unsafe-inline'` and no nonce**, as inflect's does:
  under CSP 3 a nonce there disables `'unsafe-inline'` for `style=""`
  attributes, which the UI platform writes. No `https:` wildcard and no Google
  Fonts (inflect has both); no report endpoint, which would be an
  unauthenticated write route with no Phase 0 consumer. HSTS carries no
  `preload`, a commitment the owner has not made.
- **Security headers live in one TypeScript list, repeated once in
  `next.config.mjs`** for the static assets, because the runtime image loads
  that file without the source tree. The E2E spec imports the TypeScript list
  and checks both copies on real responses.
- **The carve audit is a script, not a CI test**, because CI has no
  inflect-compliance checkout. Run for this subphase:
  `node scripts/carve-audit.mjs ../inflect-compliance` over 691 files reports
  no unlisted match and no listed-but-missing file (it reported the two files
  this subphase lifted, and the two renamed ones, before their rows were
  written). Exact blob matches and files sharing 30% of their distinctive
  lines are reported; an empty file and Next's generated `next-env.d.ts` fall
  below it.
- **Leftovers.** The tree was grepped for compliance, tenant, control,
  evidence and audit pack. Kept: provenance notes that say what inflect had and
  what was changed (they are the carve record), and ordinary English
  ("evidence for the predicate", a form control). Rewritten: un-attributed
  domain examples in comments and test fixtures (tenant slugs in route mocks,
  Evidence / Control / ISO 27001 / vendor / risk / policy fixture text,
  dashboard and date-preset examples, "tenant switcher" chrome comments),
  "edge middleware" references, and two comments that pointed at inflect
  modules that were never carried (`@/lib/nav/use-guarded-push`). Not touched:
  the third-party brand icons in `packages/ui/src/components/ui/icons/` (Veriff
  among them), lifted verbatim with the package in 0.2.
