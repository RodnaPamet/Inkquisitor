# 2026-11-18 — 0.2 UI platform

## Design

The UI platform of Phase 0.2, lifted from inflect-compliance at
`5528464fc54a8681956f3b9ce23ca9c075f0420e` (D6) and rebound to Inkquisitor:

```
packages/ui/                       @inkquisitor/ui — npm workspace, sources only, no build
  src/components/ui/…              button, card, tooltip, typography, empty/error state, skeleton, hooks, icons,
                                   charts/ (the visx chart platform: axes, areas, bars, time-series chart, …)
  src/lib/{cn,format-date,number-format}.ts
  tokens.contract.css              the token NAMES the package needs (neutral fallbacks)
src/styles/tokens.css              the palette: ink black / parchment / violet-ink accent, dark + light
tailwind.config.js                 semantic utilities over the tokens (loaded by @config in globals.css)
src/app/globals.css                the layered class recipes the primitives use
src/components/ui/                 table, filter, modal, sheet, combobox, form-field, date-picker, accordion,
                                   radio-group, toggle-group, undo toast, RichTextEditor, VersionDiff, hooks
src/components/layout/             AppShell + frame, TopChrome, SidebarNav, MobileNavDrawer, nav primitives,
                                   PageHeader, PageActions, PageBreadcrumbs, ListPageShell, EntityListPage,
                                   EntityDetailLayout, DashboardLayout, WorkspaceShell
src/components/command-palette/    the palette shell (navigation + actions + shortcuts; no entity search)
src/components/theme/              ThemeProvider (cookie + pre-paint script) and ThemeToggle
src/lib/workspace/                 WorkspaceContext (the 0.3 contract) + the server stub resolver
src/i18n.ts, messages/en.json      next-intl, cookie-based locale, English only
src/app/(app)/                     the shell layout, /books, /settings, /dev/kitchen-sink
```

Request path: the root layout resolves locale/messages (next-intl) and the
theme cookie, and wraps `Providers` (shortcut registry → palette provider →
theme → tooltip; palette, shortcut help and toaster mounted once). The
`(app)` layout resolves the workspace on the server — `getCurrentWorkspace()`,
a stub returning `null` until 0.3 — and hands it to `WorkspaceProvider`
around `<AppShell>`. Every piece of chrome reads `useOptionalWorkspace()`:
signed out, the sidebar shows the navigation and "Not signed in" and the top
chrome a theme toggle; inside a workspace, the identity block names the
person, workspace and role and the top chrome shows the workspace pill and
user menu.

## Decisions

- **Nucleo icons are not carried.** `packages/ui/src/components/ui/icons/nucleo/README.md`
  says the icons are copyrighted, redistribution is prohibited and they are
  for use only within the product they are bundled with. That is a third
  party's licence, which the same-licensor relicensing cannot reach, so it
  falls under roadmap rule 7. Every Nucleo import in the lifted code
  (checkbox, combobox, input, status badge, table, the shells) now names a
  lucide-react glyph under the same local name, so call sites are unchanged.
- **The package is lifted whole, charts included.** The brief lifts
  `packages/ui` and leaves out only named components and domain charts; the
  package's `charts/` is generic, so it came across with the `@visx/*` and
  `d3-array` dependencies it imports (item 8 bounds what is added, it does
  not license a partial lift). Its colours are six `--chart-series-*`
  gradient pairs added to `tokens.css` in both themes: series 1 is the
  accent and 2–6 are low-saturation ink companions, so a chart adds no second
  accent (the token test holds both). Inflect's app-side wrappers
  (ChartFrame and the line/radar/gantt/funnel charts) and its domain charts
  stay behind. Two gloss and fallback `#ffffff` literals were written as
  `white` to satisfy the colour guard. `/dev/kitchen-sink` draws a
  time-series chart.
- **One palette, three colours.** The token names are inflect's (every lifted
  component and utility keeps working); every value is new. Violet ink was
  chosen as the single accent because it collides with none of the four
  status hues, which stay conventional. `--brand-secondary-*` is a parchment
  neutral, not a second accent. The token test computes WCAG contrast for
  every text/surface pair in both themes, and the primary-button fill.
- **Dark stays the SSR baseline**, as in inflect: the pre-paint script picks
  the OS theme before first paint for a visitor who never chose, and nothing
  is stored until the user chooses (inflect's consent reasoning, kept).
- **Routes carry no workspace slug.** One workspace per author (D4), so
  `/books` and `/settings`; the palette's commands therefore need no slug
  either. If 0.3 wants slugs it changes `APP_ROUTES` in `SidebarNav.tsx`,
  which the palette test reads.
- **`WorkspaceContext` throws on `null` in `useWorkspace()`**, not only
  outside a provider: a signed-out provider is the common case today, and a
  caller that needs a workspace must not render a placeholder one.
- **Smart back and route-classified H1s were removed** from `PageHeader` /
  `EntityDetailLayout` / `EntityListPage`: both read inflect's table of
  compliance routes. `PageHeader` takes an explicit `titleHidden` instead.
- **The command palette is a shell.** Entity search, its filter chips and
  recents are compliance-entity features; the surface keeps the Dialog,
  cmdk, Navigation/Actions/Shortcuts groups and keycap rendering, so entity
  search later is another `Command.Group`.
- **Layout modules not lifted, and why.** `environment-badge.tsx` names
  environments from inflect's deploy hostnames (`staging.`, `-dev.`);
  Inkquisitor's environments are decided with its deploy in 0.4, and a badge
  guessing from hostnames before then would be wrong. `ClientProviders.tsx`
  mounts inflect's onboarding tour, SWR devtools and web-vitals reporter,
  none of which is carried. `WorkspaceShell` (the canvas page shell) IS
  lifted, although the canvas is Phase 3: it is generic layout and the brief
  lifts every shell.
- **The kitchen sink shows every lifted module that renders on its own**, and
  its header lists what it does not (helpers, internals that render only
  inside a shown primitive, and the app chrome the page itself sits in).
  Each probe drives its primitive (opens the tooltip, fires the undo toast,
  flips the theme) rather than finding the sink's own trigger button.
- **The kitchen sink passes its search params to its filter toolbar** as
  `serverFilters`. The toolbar syncs state to the URL, and without the
  hand-off a reload of `?stage=Drafting` rendered a pill only on the client:
  a hydration error. Inflect's list pages all pass `serverFilters`; the sink
  had dropped it. The second toolbar (inside the EntityListPage section)
  keeps `syncUrl: false`, so one toolbar owns the URL.
- **`inert` is a boolean under React 19.** The batch-action toolbar passed
  `inert=""` (a React 18 workaround), which React 19 reads as false and
  drops, so the hidden toolbar's controls stayed in the tab order. It now
  passes `inert={selectedCount === 0}`.
- **The `src/components/ui/*` re-export files stay.** inflect moved ten
  primitives into its package and kept these paths as shims; the app-side
  primitives and the ported suites import them as inflect's do, which keeps
  every lifted file comparable with its source. Their headers now say so
  rather than narrate inflect's migration.
- **Every primitive the sink shows has a behavioural suite.** 34 of inflect's
  suites for lifted primitives (card, typography, error state, initials
  avatar, the data table's resizing, expansion and mobile cards, …) were
  ported with only the specifier rename and fixture words; where inflect had
  no suite (status badge, skeleton, page header and actions, dashboard
  layout, field group, scroll and animated-size containers, page
  breadcrumbs, workspace shell, theme toggle beyond its tooltip cases) one
  was written.
- **English only**, so `LocaleSwitcher` and the user menu's language row are
  not lifted; the locale cookie and `SUPPORTED_LOCALES` remain, so a second
  locale is a catalogue plus one array entry. `messages/en.json` holds only
  keys something reads (found by scanning the lifted code, then the missing
  ones the ported suites surfaced, such as `ui.combobox.*`, read through a
  helper that receives `t`).
- **The React-Compiler hook rules run at `warn` on the lifted directories
  only**, as inflect runs them everywhere; new code keeps them at `error`.
- **The kitchen sink is a 404 when `NODE_ENV=production`**, decided in the
  page with `notFound()`; verified by a unit test, against `next start`, and
  in the E2E suite. A `KITCHEN_SINK_PRIMITIVES` list plus an exhaustive
  `Record` of probes makes adding a primitive without a test a compile error.
  The suite found a real defect on the way: the checkbox section's heading
  reused the checkbox's `id`, so its label pointed at the heading.
- **The hooks barrel check is by identity** (`barrel[name] === module[name]`)
  rather than inflect's regex; it found `useRegisteredShortcuts` missing.
- **Guards scan string content through the TypeScript AST**, so a comment
  describing a banned colour is never reported and a class in a template
  literal always is. `tests/helpers/source-blocks.ts` was not lifted here:
  it is 0.4's. The two ported suites that used it inline a comment strip, or
  drop the section that needed it.
- **`filter-examples.ts` was deleted**: nothing imported it and it carried
  inflect's control and risk enums. The presets API takes `workspaceSlug`.
- **Not added**: `src/lib/security/sanitize.ts`. The roadmap pairs it with
  the editor, but nothing persists editor output yet; it comes with the first
  write path (Phase 1), where it must run server-side.
